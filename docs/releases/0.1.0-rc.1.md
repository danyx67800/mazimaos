# MazimaOS 0.1.0-rc.1

This is a **pre-release candidate**, not a verified 1.0.0 release.

## Artifacts

- `mazima-0.1.0-rc.1-amd64.iso` — Debian 13 live image for x86_64
- `mazima-0.1.0-rc.1-amd64.iso.sha256`
- `mazima-0.1.0-rc.1-linux-amd64.tar.gz` — daemon, UI and store bundle
- `mazima-manifest.json` and `mazima-manifest.json.sig` — OTA manifest and signature

The ISO and bundle embed the OTA public key configured for this release. The
OTA manifest uses the `beta` channel so stable installations do not select this
prerelease automatically.

## What is included

- Browser desktop, setup, login, sessions, settings, audit, updates, Docker and
  Tailscale management surfaces.
- Debian live-build configuration with systemd, Caddy, Avahi, nftables and
  restic backup units.
- File Browser as the only bundled app catalog entry.
- Playwright end-to-end coverage for setup, desktop, command palette, theme,
  PWA shell and login/logout.

## Not verified in this release

The following items still require manual verification on supported hardware:

- First boot of the ISO in UEFI and legacy mode.
- Linux streaming with Xvfb, ffmpeg, xdotool and clipboard integration.
- Tailscale login, Serve and Funnel.
- Signed OTA install and rollback.
- App installation through Caddy.
- restic restore.

See `docs/MANUAL-TESTING.md` for the full matrix. Do not expose this image
directly to the public internet. Caddy uses an internal CA; trust its root CA
or use a reviewed reverse proxy before remote use.

## Quick start

```sh
sha256sum -c mazima-0.1.0-rc.1-amd64.iso.sha256
sudo dd if=mazima-0.1.0-rc.1-amd64.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

Boot the machine, open `https://mazima.local`, and retrieve the one-time setup
token from the console with:

```sh
sudo mazimactl setup-token --config /etc/mazima/config.json
```

The live session keeps state in RAM by default. See `image/README.md` for
persistence and backup notes.
