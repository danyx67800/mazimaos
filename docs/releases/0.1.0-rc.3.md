# MazimaOS 0.1.0-rc.3

This is a **pre-release candidate**, not a verified 1.0.0 release.

## Changes since 0.1.0-rc.2

- Added a guided first-boot setup on the console. On a fresh boot,
  `mazima-setup.service` starts on `tty1` before the login prompt and asks for
  language, timezone, administrator username, display name and password.
- The wizard talks to the local `mazimad` API using the one-time token from
  `/var/lib/mazima/setup.token`, so the token no longer has to be copied by
  hand. The token is removed after setup and the wizard does not run again.
- The selected timezone is applied to the live system with `timedatectl`.
- Cancelling the wizard still leaves the documented fallback available:
  log in as `user` / `live` and run
  `sudo mazimactl setup-token --config /etc/mazima/config.json`.
- The wizard deliberately keeps the hostname `mazima` and the URL
  `https://mazima.local`; changing the OS hostname is not automated yet.

## Artifacts

- `mazima-0.1.0-rc.3-amd64.iso` — Debian 13 live image for x86_64
- `mazima-0.1.0-rc.3-amd64.iso.sha256`
- `mazima-0.1.0-rc.3-linux-amd64.tar.gz` — daemon, UI and store bundle
- `mazima-manifest.json` and `mazima-manifest.json.sig` — OTA manifest and signature

The ISO and bundle embed the OTA public key configured for this release. The
OTA manifest uses the `beta` channel so stable installations do not select this
prerelease automatically. The guided console wizard is part of the ISO; the
OTA tarball updates the daemon, UI and store only and does not replace the boot
image.

## What is included

- Browser desktop, setup, login, sessions, settings, audit, updates, Docker and
  Tailscale management surfaces.
- Guided console first-boot setup plus the browser setup fallback.
- Debian live-build configuration with systemd, Caddy, Avahi, nftables and
  restic backup units.
- File Browser as the only bundled app catalog entry.
- Playwright end-to-end coverage for setup, desktop, command palette, theme,
  PWA shell and login/logout.

## Not verified in this release

The following items still require manual verification on supported hardware:

- First boot of the ISO in UEFI and legacy mode, including the guided console
  wizard and the fallback token path.
- Linux streaming with Xvfb, ffmpeg, xdotool and clipboard integration.
- Tailscale login, Serve and Funnel.
- Signed OTA install and rollback.
- App installation through Caddy.
- restic restore.

See `docs/MANUAL-TESTING.md` for the full matrix. Do not expose this image
directly to the public internet. Caddy uses an internal CA; trust its root CA
or use a reviewed reverse proxy before remote use.

## Quick start

```sh
sha256sum -c mazima-0.1.0-rc.3-amd64.iso.sha256
sudo dd if=mazima-0.1.0-rc.3-amd64.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

On first boot, complete the guided console wizard. If you cancel it, log in as
`user` with password `live`, run:

```sh
sudo mazimactl setup-token --config /etc/mazima/config.json
```

Then open `https://mazima.local` and paste the token. The live session keeps
state in RAM by default. See `image/README.md` for persistence and backup
notes.
